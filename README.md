# E-Commerce Order Management System

Java 17 / Spring Boot / Spring Data JPA / MySQL backend portfolio project.

## Planned features
- Product and customer REST APIs
- Shopping cart and checkout
- Inventory management
- Validation and exception handling
- Unit tests

## Status
Work in progress. Source code is being added and has not yet been verified by a full Maven build.

## Development
Use Java 17, Maven and MySQL 8. Do not use this starter for production without further testing and security review.
